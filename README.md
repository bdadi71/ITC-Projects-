# ITC Projects

A collection of four small web apps built with vanilla HTML, CSS, and JavaScript — each with a shared animated night-sky theme.

🔗 **Live site:** https://bdadi71.github.io/ITC-Projects-/

## Projects

### 📝 To-Do List
Add, complete, filter, and delete tasks. Progress is saved automatically in your browser.

### 🔐 Password Generator
Generate strong, random passwords with adjustable length and character sets (uppercase, lowercase, numbers, symbols). Includes a live strength meter and one-click copy.

### 💬 Random Quote Generator
Fetches a random quote from a public API with one click. Includes copy and share-to-X options, with offline fallback quotes if the API is unavailable.

### 🧮 Grid Calculator
A responsive calculator supporting basic arithmetic, percentages, and full keyboard input.

## Tech
- HTML5
- CSS3 (animations, glassmorphism, canvas-based starfield background)
- Vanilla JavaScript (no frameworks or libraries)

## How to Run
No build steps needed — just open any `.html` file in a browser, or visit the [live site](https://bdadi71.github.io/ITC-Projects-/).
